РЕАЛЬНАЯ ЗАДАЧА

Avaya не создаёт единого потока CDR

CM передаёт этапы вызова и condition codes. SM экспортирует XML сессий. SBCE отправляет CSV пограничных сессий. Equinox формирует XML конференций и событий. CDR AVAYA обеспечивает надёжную доставку и хранение, не смешивая разные модели корреляции.

Источники CDR

Communication Manager

TCP CDR, сохранение RAW и цепочки вызовов по UCID.

Session Manager

Расширенный XML сессий, получаемый по SFTP.

SBCE

CSV пограничных сессий, принимаемые по SFTP.

Equinox Management

XML конференций, событий и участников.

Other

Универсальный сторонний источник CDR разрабатывается.

Обработка источников

Communication Manager

Customized и unformatted CDR по TCP, сохранённые RAW и цепочки вызовов по UCID.

Проверено на Avaya Aura 8.1; стенд VMware принял 50 000 синтетических записей со скоростью 10 000 записей/с без потерь.

Руководство PDFНагрузочный тест

Session Manager

Расширенный XML по SFTP с сохранением источника, RAW и связанных деталей сессии.

Получение данных и связанные «Детали» проверены на стенде Avaya Aura 8.1.

Руководство PDF

SBCE

CSV по SFTP с сохранением связанных RAW, Routing Profile и Server Flow.

SFTP-загрузка и «Детали» сессии проверены на стенде Avaya Aura 8.1.

Руководство PDF

Equinox Management

XML конференций из подготовленного каталога с сохранением событий, участников и изменённых файлов.

Получение и повторная обработка проверены на Equinox Management 9.1.12.

Руководство PDF

Other

Универсальный сбор и разбор сторонних CDR находится в разработке.

Подтверждённых данных интеграционного и нагрузочного тестирования пока нет.

РАЗВЁРТЫВАНИЕ

Онлайн-установка или один автономный комплект

wget https://github.com/vovan-T/CDR-AVAYA/releases/latest/download/install.sh
chmod +x install.sh
sudo ./install.sh

Установщик разворачивает контейнеры приложения и PostgreSQL. Автономный режим формирует переносимый комплект образов и установщик для изолированного сервера.
