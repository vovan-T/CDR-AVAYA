РЕАЛЬНАЯ ЗАДАЧА

Avaya не создаёт единого потока CDR

CM передаёт этапы вызова и condition codes. SM экспортирует XML сессий. SBCE отправляет CSV пограничных сессий. Equinox формирует XML конференций и событий. CDR AVAYA обеспечивает надёжную доставку и хранение, не смешивая разные модели корреляции.

ОПИСАНИЕ ФУНКЦИОНАЛА

От исходной записи до рабочего журнала

Communication Manager

Принимает customized или unformatted CDR напрямую по TCP и сохраняет каждую принятую исходную запись до формирования журнала вызовов.

  • Отдельные порты listener и схемы полей для каждой ACD.
  • Устойчивая очередь SQLite WAL защищает принятые пакеты при недоступности PostgreSQL.
  • Исходные RAW-записи остаются доступными для проверки и повторной обработки.
  • Корреляция по UCID пересобирает переводы, конференции и поздние этапы вызова.
  • В деталях сохраняются транки, VDN, condition codes, маршруты и логические этапы вызова.

Проверено

Avaya Aura 8.1. Стенд VMware обработал 50 000 синтетических записей CM при подаче 10 000 записей/с без потерь и восстановил очередь после остановки PostgreSQL и listener.

Session Manager

Забирает расширенный XML CDR Session Manager по SFTP и преобразует данные сессий в отдельный журнал с поиском.

  • Поддерживает один или несколько независимо настроенных серверов SM.
  • Сохраняет идентификатор сервера-источника и импортированные RAW-данные.
  • Ведёт учёт скопированных файлов и не импортирует один источник повторно.
  • Показывает собственные поля SM через отдельный каталог колонок «ВИД».
  • Связывает строку журнала со всеми исходными RAW-записями.

Проверено

На стенде Avaya Aura 8.1 проверены загрузка расширенного XML, защита от повторного импорта, идентификация источника, сохранение RAW и связанные «Детали».

PDF: Session Manager

SBCE

Принимает CSV, которые SBCE отправляет в изолированные SFTP-каталоги, и создаёт отдельный журнал сессий для каждого настроенного экземпляра.

  • Общий пользователь CDR_User принимает файлы в нумерованные каталоги экземпляров.
  • Защитная задержка не позволяет забрать CSV, пока SBCE ещё записывает файл.
  • Строки группируются по идентификатору сессии с консервативными резервными признаками.
  • Маршрут берётся из Routing Profile; доступны Server Flow и исходные поля.
  • «Детали» показывают все связанные RAW-строки, из которых собрана сессия.

Проверено

На стенде Avaya Aura 8.1 проверены SFTP-загрузка, отдельные каталоги, защита незакрытого файла, связанные RAW, Routing Profile и Server Flow.

PDF: SBCE

Equinox Management

Забирает XML конференций Equinox, сохраняет события и участников и формирует отдельный журнал конференций.

  • Получает подготовленные XML с настроенного сервера Equinox Management.
  • SHA-256 определяет новые и изменённые файлы независимо от их имени.
  • Данные конференций, событий и участников остаются разделёнными и проверяемыми.
  • Schedule, Reschedule и Cancel можно добавлять к обычному представлению.
  • RAW сохраняется для повторной обработки при изменении логики.

Проверено

На Equinox Management 9.1.12 проверены импорт конференций, событий и участников, определение изменённых файлов и повторное получение.

PDF: Equinox Management

Other
