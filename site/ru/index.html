РЕАЛЬНАЯ ЗАДАЧА

Avaya не создаёт единого потока CDR

CM передаёт этапы вызова и condition codes. SM экспортирует XML сессий. SBCE отправляет CSV пограничных сессий. Equinox формирует XML конференций и событий. CDR AVAYA обеспечивает надёжную доставку и хранение, не смешивая разные модели корреляции.

ПОДДЕРЖИВАЕМЫЕ ИСТОЧНИКИ

Каждый источник сохраняет свою семантику

Communication Manager

Приём TCP, customized и unformatted форматы, пересборка цепочек UCID, транки, VDN и condition-code в деталях.

Обработка CM

Session Manager

Загрузка расширенного XML по SFTP, сохранение исходных записей, идентификация сервера и связанные детали.

Обработка SM

SBCE

Каталоги SFTP, корреляция по сессии, Routing Profile, Server Flow и все исходные строки.

Обработка SBCE

Equinox Management

XML конференций, участники, контроль изменений SHA-256 и безопасное повторное получение.

Обработка Equinox

ПУТЬ ДАННЫХ

Принятые данные можно восстановить

Сборщики фиксируют пакеты в SQLite WAL до подтверждения приёма. Запись PostgreSQL RAW остаётся необработанной, пока процессор источника не запишет вызов и детали одной транзакцией. Поздняя запись CM пересобирает всю цепочку UCID.

ЭКСПЛУАТАЦИЯ

Состояние системы видно

  • Исходные RAW-записи не теряются.
  • Очереди и службы отображаются в диагностике.
  • Вызов раскрывается в упорядоченные связанные детали.
  • Обновления проверяются SHA-256 и поддерживают rollback.
  • Есть Backup/Restore, Support Pack и журнал действий.

РАЗВЁРТЫВАНИЕ

Онлайн-установка или один автономный комплект

wget https://github.com/vovan-T/CDR-AVAYA/releases/latest/download/install.sh
chmod +x install.sh
sudo ./install.sh

Установщик разворачивает контейнеры приложения и PostgreSQL. Автономный режим формирует переносимый комплект образов и установщик для изолированного сервера.
