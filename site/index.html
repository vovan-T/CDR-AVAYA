THE ACTUAL PROBLEM

Avaya does not produce one universal CDR stream

CM sends call legs and condition codes. SM exports session XML. SBCE delivers border-session CSV files. Equinox produces conference and event XML. CDR AVAYA keeps their transport and storage reliable without pretending that their correlation models are identical.

FUNCTIONAL DESCRIPTION

From source record to operational journal

Communication Manager

Receives customized or unformatted CDR directly over TCP and retains every accepted source record before building the call journal.

  • Separate listener ports and field layouts for each ACD.
  • Durable SQLite WAL spool protects accepted batches while PostgreSQL is unavailable.
  • Original RAW records remain available for inspection and reprocessing.
  • UCID correlation rebuilds transfers, conferences and late call stages.
  • Trunks, VDNs, condition codes, routes and logical call stages remain visible in Details.

Verified

Tested with Avaya Aura 8.1. The VMware load test processed 50,000 synthetic CM records at an offered rate of 10,000 records/s without loss and recovered queued data after PostgreSQL and listener failures.

Session Manager

Retrieves extended Session Manager CDR XML over SFTP and converts session data into a dedicated searchable journal.

  • Supports one or more independently configured SM servers.
  • Preserves the source server identity and imported RAW data.
  • Tracks copied files so the same source is not imported twice.
  • Exposes SM-specific fields through its own View column catalog.
  • Links each journal row back to the contributing RAW records.

Verified

Extended XML retrieval, duplicate-file protection, source identity, RAW preservation and linked Details were checked on the Avaya Aura 8.1 integration stand.

PDF manual: Session Manager

SBCE

Accepts CSV files pushed by SBCE into isolated SFTP folders and builds a separate session journal for every configured instance.

  • A shared CDR_User account accepts uploads into numbered instance folders.
  • A file-age guard avoids importing a CSV while SBCE is still writing it.
  • Rows are grouped by session identity with conservative fallbacks.
  • Routing Profile provides the route; Server Flow and source fields remain available.
  • Details show every linked RAW row used to build the session.

Verified

SFTP upload, isolated instance folders, file-age protection, linked RAW Details, Routing Profile and Server Flow were checked on the Avaya Aura 8.1 integration stand.

PDF manual: SBCE

Equinox Management

Collects Equinox conference XML, preserves events and participants, and builds a conference-oriented journal.

  • Retrieves staged XML from the configured Equinox Management host.
  • SHA-256 identifies new or changed files instead of trusting filenames alone.
  • Conference, event and participant data remain separated and traceable.
  • Schedule, Reschedule and Cancel records can be added to the normal view.
  • RAW remains available when processing logic must be rerun.

Verified

Conference, event and participant import, changed-file detection and repeat collection were checked with Equinox Management 9.1.12.

DEPLOYMENT

Install online or prepare one offline bundle

wget https://github.com/vovan-T/CDR-AVAYA/releases/latest/download/install.sh
chmod +x install.sh
sudo ./install.sh

The installer deploys the application and PostgreSQL containers. The offline mode downloads a transferable image bundle and installer for an isolated server.
